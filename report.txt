  [FIX-1] Add FAQPage schema to /faq
  ────────────────────────────────────
  File   : app/faq/page.tsx  (or a new server component wrapper)
  Reason : Google shows FAQ rich results (expandable Q&A in SERPs) for
           pages with FAQPage schema. The /faq page has all the data in
           faqData[] already — it just needs to be emitted as JSON-LD.
  Fix    : Add a <StructuredData> component with:
           {
             "@context": "https://schema.org",
             "@type": "FAQPage",
             "mainEntity": allFaqItems.map(item => ({
               "@type": "Question",
               "name": item.q,
               "acceptedAnswer": {
                 "@type": "Answer",
                 "text": item.a
               }
             }))
           }
  Note   : Keep the FAQ page as "use client" — add the schema in the
           server-side page.tsx route file using a StructuredData component.

  [FIX-2] Add Article schema to /events/[slug]
  ──────────────────────────────────────────────
  File   : app/events/[slug]/page.tsx
  Reason : Event/article pages have no JSON-LD despite having rich content.
           NewsArticle schema enables Google News eligibility and article
           rich results.
  Fix    : In the page.tsx, render a <StructuredData> server component with:
           {
             "@context": "https://schema.org",
             "@type": "NewsArticle",
             "headline": post.title,
             "description": post.excerpt,
             "datePublished": post.dateISO,
             "dateModified": post.dateISO,
             "author": { "@type": "Organization", "name": "SWEDINOX AB" },
             "publisher": {
               "@type": "Organization",
               "name": "SWEDINOX AB",
               "logo": { "@type": "ImageObject", "url": "https://swedinox.se/logo.png" }
             },
             "url": "https://swedinox.se/events/" + post.slug
           }
  Note   : Also add BreadcrumbList:
           Home > Events > [Post Title]
